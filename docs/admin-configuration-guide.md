# 管理员简化配置操作指南

日期：2026-11-23。适用范围：本次代码候选，发布后按实际版本验收。

## 配置入口

有效平台管理员可直接维护下表配置，无需另一个管理员复核。所有保存均记录执行者、原因、时间和配置版本；支持组成员增补一并留痕。

| 入口 | 可维护内容 |
| --- | --- |
| 角色授权 → 新增角色人员 | 平台管理员、组长、调度员对应的人员、支持组和有效期；可配置本人 |
| 支持组 | 新增、改名、停用/恢复支持组，添加或移除成员 |
| 支持组 → 支持组与成员 → 成员权限（盾牌按钮） | 按支持组维护 P1 复核、知识编辑、知识审校；按具体申请类服务维护目录发布人 |
| 岗位任职 | 选择真实员工、岗位、主责/备岗、开始和结束时间；一人多岗、一岗多人 |
| 服务组织 → 责任域 / 业务系统 / 岗位 | 自定义名称、层级、所属支持组及启用状态 |
| 服务组织 → 目录维护 / 服务映射 | 新增或编辑服务，关联责任域、业务系统、主办岗位和协办岗位 |

业务岗位可以自定义；权限角色沿用平台已经实现的动作定义。岗位任职不会自动授予平台管理权。管理员仍保留员工身份，可正常提交自己的工单。

## 新增服务工程师

1. 确认员工已从钉钉可信通讯录同步。配置表单内选择已有员工；“人员同步”页面当前显示统计和同步记录，不提供新建企业身份。
2. 在“岗位任职”新增任职，选择岗位、人员、主责或备岗及有效期，填写原因后“保存并生效”。未加入目标支持组的员工会在同一事务中自动加入；管理员也可以先在“支持组”手工添加。
3. 在“服务组织 → 服务映射”将服务目录关联到主办岗位，必要时关联业务系统及协办岗位。预览有效候选后保存。服务组织整份草稿使用同一版本原子发布。
4. 用新工单验证候选、分派、工程师本人接收及通知回执。配置岗位只确定候选资格，不将所有工单直接标记为本人已经接收。

例如：“ERP 无法登录”服务关联“ERP 运维工程师”岗位，再将实际员工配置到该岗位。以后人员更换只需维护任职，不必逐个修改服务目录。

## 调整 P1 复核等成员权限

进入“支持组 → 支持组与成员”，选择目标支持组，在员工行点击盾牌按钮“配置某某权限”。勾选或取消 P1 复核、知识编辑、知识审校，或选择具体申请类服务的发布权限，填写变更依据并确认内容边界后，点击“保存并生效”。有效平台管理员直接保存，不需要另一名管理员批准。目标员工须先加入该支持组。

P1 复核资格不等于工单处理岗位，也不会自动成为负责人；本人提交或本人调整的工单仍由其他复核人确认。移除最后一位有效 P1 复核人，或导致待复核工单、未完成知识文章无人承接时，系统拒绝本次保存，应先配置接替人。全部前后快照在“操作日志 → 角色授权”集中查询。详细权限核查见[管理员成员权限配置设计](admin-member-privileges.md)。

## 调整与退出

- 更换负责人时先建立接替人的有效任职，再停用原任职；已有工单通过交接流程移交，历史负责人和 SLA 保留。
- 撤销权限角色不自动移除支持组成员；移除成员前需处理有效任职、在办工单及其他责任依赖。
- 停用岗位、业务系统、责任域或支持组前检查启用引用及人员覆盖，失败时本次保存全部回滚。
- 平台管理员撤销仍须保留两名其他有效管理员；人员真实离职由可信人员源执行停用，不删除历史员工记录。
- 其他组长使用限定范围的提案与独立复核。业务 OA 审批、交付复核、P1 独立确认、逐单继续处理授权及其他配置流程继续沿用既有规则。

## 发布与验收

配置维护与历史查询分开：管理员在各配置页面维护当前配置，统一从“操作日志”查询历史；“查看相关日志”可直接带入当前模块和对象。配置页面仍保留待处理审批，工单详情仍保留业务时间线。详见[集中操作日志设计与验收](centralized-operation-logs.md)。

本次增加迁移 `044_admin_configuration.sql`，旧审批记录保留，直接配置标记 `ADMIN_DIRECT`。发布前完成同一提交的 CI、制品核验和备份；迁移后验证管理员可保存、普通用户不可越权、真实员工可选择、路由候选正确以及真实钉钉到人通知。隔离测试结果不等于服务器已发布或真实通知已通过。
