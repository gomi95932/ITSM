- `006_request_catalog.sql` 增加按服务项显式任命的发布人、不可变目录版本和发布/下线审计。生产默认没有发布人；CI 测试单独创建任命，不以支持组成员身份自动赋权。

## 员工申请入口候选

- 默认关闭。只有显式开启 `ENABLE_REQUEST_INTAKE`、配置 OA 和受控交付，并将确切 `服务编码@表单版本` 列入 `REQUEST_INTAKE_CATALOG_VERSIONS` 后，员工才可提交该目录版本。发布新版不会自动继承开放资格；现场启用须先完成真实审批、交付和回收验收。
- 提交时校验有效天数、真实申请人及审批人的身份映射、主管映射复核有效期，以及申请人、代提交人和审批人职责分离。申请、目录快照、OA 排队、SLA、审计、通知出站在同一事务提交。审批等待暂停解决时钟，不暂停响应时钟。
- 新增 HTTP 与桌面、手机浏览器回归；隔离 CI 仅对 API 传入合成身份，Worker 不发起真实审批或消息。模拟验证只覆盖提交并排队、进度读取、重复提交、权限与事务回滚，不代表钉钉实际审批或下游交付已跑通。
- 完整的监控与配置项关联仍为二期 P2-02/P2-03，完整安全事件为三期 P3-01；一期安全入口保护仍须验收。
