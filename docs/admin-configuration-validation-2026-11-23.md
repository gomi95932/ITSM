# 管理员简化配置验证记录

日期：2026-11-23。

## 实现范围

- 平台管理员可直接保存角色授权、支持组及成员、服务组织与目录映射、岗位任职，无需第二名管理员复核。
- 可为本人或已从可信钉钉通讯录同步的员工配置；岗位任职不等于平台管理员授权。
- 角色的支持组作用域配置、有效岗位任职可在同一事务中补入支持组成员，保留审计记录。
- 责任域、业务系统、岗位和服务目录可维护；权限角色仍使用已实现的权限定义，不支持任意新建权限动作。
- 保留普通用户权限边界、配置版本校验、依赖校验、人员有效性检查及已有工单交接约束。
- 直接配置标记为 `ADMIN_DIRECT`，不冒充独立复核。业务 OA 审批及其他既有独立确认流程未放开。
