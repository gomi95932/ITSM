# 一期业务核心缺口与验收清单

核对日期：2026-11-22。源码基线：`59b01c5bccfd2e455bc81e32f39889a45031454e`。本批候选改动以所在分支及 CI 为准，未合并和未部署的改动不计入运行环境完成度。

## 范围与证据规则

先交付可独立使用的 ITSM 核心 S1，再交付钉钉智能体简单问答/跳转 S2、智能体编排 S3、完整联调 S4。监控与 CI 关联保留二期，完整安全事件保留三期。普通受理的敏感内容保护仍是一期开启入口的前置。

状态分为“基线已有代码”“本批补齐待验证”“自动测试通过”“真实联调通过”“业务签收”，不得混用。历史 CI 和模拟身份只能证明对应版本的自动验证，不代表本批、真实通知、真实 OA 或用户验收。具体测试运行和内部环境记录保存在公司受控文件，不进入公开仓库。

## 未关闭缺口及处理路径

| 缺口 | 阻断范围 | 实现与验收动作 |
| --- | --- | --- |
| GAP-01 服务日历不能日常维护 | 真实 SLA 承诺 | 本批新增提案/复核 API、日期及时间管理 UI、不可变版本、快照回归；按 `p1-service-calendar.md` 验收 |
| GAP-02 门户缺独立生产身份入口 | 脱离钉钉的正式使用 | 本批新增默认关闭的 OIDC；必须完成受信身份映射及真实 IdP UAT；不用开发账号替代 |
| GAP-03 厂区路由及隔离 | 多厂区上线；对应蓝图 B01/B02/B16/B23 等厂区部分 | 本批候选新增经独立复核的厂区/人员/服务/组/岗位范围及路由，工单保存可信归属和派单快照；查询、处理、交付、知识、通知和报表复查当前范围。未知归属拒绝受理并提示服务台核实，不默认跨厂。启用前须关闭所有缺少厂区的历史在途工单；无厂区历史结束单仅申请人可读。迁移 040 及 operations-scope 集成、桌面/手机测试待本批 CI 验证；真实厂区配置另行签收 |
| GAP-04 真实身份与管理员交接 | 企业试点开放 | 使用可信目录同步、真实角色提案和双人复核；已有管理员历史但无人可登录时按受控带外变更恢复，不能重命名演示人员或清历史 |
| GAP-05 真实消息、OA、手机 H5 | 钉钉入口及申请正式开放 | 指定试点人员验证送达、接单、补充、关闭及回写；OA 覆盖失败与对账；配置开关保持按版本开放 |
| GAP-06 真实附件、运行与业务签收 | 带附件和真实用户运营 | 真实扫描器、权限及备份恢复；本批部署后按约定负载回归并至少 30 分钟稳定性测试，记录 5xx、成功率及延迟；业务签收不能沿用旧报告 |
| GAP-07 每服务独立 SLA 模板 | 业务要求不同服务采用不同 SLA 承诺时 | 本批候选复用既有 SLA 引擎，新增服务到模板配置、P1–P4 响应/解决目标和不可变周期快照；无服务模板时沿用全局策略。模板发布不回写在途周期；重开新周期使用当时批准配置。数据库、旧单、优先级与重开回归待本批 CI；业务时限须另签收 |
| GAP-08 组长任职维护及强制接管 | 启用对应蓝图管理动作时 | 本批候选复用服务组织提案/独立复核，组长仅维护本组任职、不可自授任职或修改组织结构；紧急撤销立即生效并留不可变记录。`FORCE_TAKEOVER` 仅当前组长可指定同组、当前岗位及厂区合格人员，真实改变责任人，保留等待状态和 SLA，不伪造本人接收或首响。并发、重试、撤权及审计待 CI；值班排班、服务经理/审计员独立角色仍不在本批实现中 |

GAP-01/02/03/07/08 的“本批候选”只表示代码存在，须附对应提交的完整 CI 才能标自动测试通过；真实配置/联调项仍不能标为已关闭。

逐项操作、预期结果和证据要求见 `phase1-core-uat-cases.md`，配置操作见 `p1-operations-scope.md`。业务若暂不启用这些管理能力，须由负责人明确记录试点边界，不能由开发静默删减验收要求。

## 实际执行及发布门槛

1. 从干净 main 分支复用既有模块；保持其他智能体工作区未提交改动独立，避免把未注册服务和迁移序号冲突带入本批。
2. 在远程隔离目录执行构建、类型检查、单元测试；在 GitHub 一次性环境执行完整数据库集成、迁移恢复、安全扫描及桌面/手机浏览器测试。
3. 记录确切 SHA、CI run、失败修复及截图。所有必需检查通过后，才可合并形成一个集中发布候选。
4. 经既有发布流程集中部署、备份迁移及部署后验收；不对每个小功能分别部署。运行环境验收另记录，不把 PR 通过视为服务器已更新。
5. 真实身份/通知/OA/附件按范围逐项签收；厂区隔离未完成前不得宣布多厂区正式可用。S1 门户与 S2/S3/S4 各自验收，避免被渠道编排阻塞全部核心开发。
