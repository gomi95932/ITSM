# 一期服务日历管理

本批在既有 SLA 快照和计时器上补充配置界面及独立复核，不替换工单状态机。入口为管理员的“分级与时限 → 服务日历配置”。

## 配置与生效

- 支持中国时区、每日整点开始和结束时间、节假日及调休工作日。日期须真实、唯一，节假日和工作日不得交叉。
- 一名有效全局平台管理员提案，另一名有效全局平台管理员批准或拒绝；不允许自己批准。批准时再次验证提案人的当前授权及基线版本。
- 提案期间不影响计时，批准后追加新版本；历史版本禁止更新和删除。恢复旧配置须创建并批准新版本。
- 新 SLA 周期保存批准时的完整日历快照；已有周期不因配置变更而重新计时或延后承诺。接单时限沿用已批准的组级接单策略与其独立日历，不被全局解决时限日历静默覆盖。
- P1 的连续计时规则保持原样；计时连续不代表已有 7×24 值班人员。上线前业务负责人须确认工作时间、值班和节假日。

## API

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/admin/sla-calendar` | 当前版本、提案及历史 |
| `POST /api/v1/admin/sla-calendar` | 提交含 UUID、当前版本、配置和原因的提案 |
| `POST /api/v1/admin/sla-calendar/:id/review` | 按提案版本独立批准或拒绝 |

写入复用会话、CSRF、普通内容筛查、角色锁、事务和操作审计；同 UUID 同内容可重试，换内容拒绝。并行提案中只有基于当前版本的一条能发布，旧提案须拒绝或重新提交。
