# 支持组与成员维护候选

日期：2026-11-15。状态：代码候选，尚未完成 CI、合并、开发机部署及真实人员验收。

## 本切片

- 管理入口“支持组管理”，复用员工身份，不新建登录账号。
- 平台管理员可创建支持组、按版本修改组名；不提供删除或停组，避免绕过目录与工单归属检查。
- 有效组长只能管理本组，平台管理员可维护全部组；配置权限不赋予工单正文读取权。
- 新增、移除成员均形成提案；另一名平台管理员复核，且不能是变更对象。提案人不能变更自己的成员关系。
- 新增成员须在职；提案不立即产生成员资格。组版本变化后的旧提案不可批准，可拒绝后重提。
- 移除检查在办工单、待接收交接、未回收交付及未收尾知识草稿。存在责任时返回明确冲突，不等待后台异步清理后才收口。
- 最后一名在职成员、最后一名有效组长和最后一名在职 P1/知识专项人员不可直接移除；先安排替补。紧急账号停用仍走既有受控停用渠道，不受正常离组流程阻断。
- 移除时同事务撤销该组 ACTIVE/PENDING 角色、清理依赖成员资格的专项任命、注销会话并记审计。重新入组不自动恢复历史角色；若存在外部改库遗留的未撤销角色，新增被阻止，须先复核撤销。
- 成员变更与特权工单动作共用授权事务锁；知识维护及交付操作锁定成员资格，防止离组竞态绕过。

## 接口

统一前缀 `/api/v1/admin/support-groups`，所有写操作沿用会话 CSRF 和普通内容声明。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/` | 授权范围组列表、人数与待复核计数 |
| GET | `/people?q=...` | 至少两字符搜索在职员工，仅返回 ID/姓名，最多 50 条 |
| GET | `/{id}` | 组版本、成员和最近 100 条变更 |
| GET | `/{id}/history` | 最近 200 条组配置与成员变更审计 |
| POST | `/` | 创建组，编码不可复用覆盖 |
| PATCH | `/{id}` | 按 `expectedVersion` 修改名称并记录原因 |
| POST | `/{id}/members` | UUID 提案、人员、ADD/REMOVE、组版本、依据；同 ID 同内容可重放 |
| POST | `/{id}/members/{changeId}/review` | 独立复核、提案版本、APPROVE/REJECT、依据 |

新增迁移 `013_support_group_administration.sql`，不修改 001–012 历史迁移。组名修改及成员批准都会增加组版本；并行提案中其他旧版本需重新复核，界面保留拒绝入口。
