# Phase 1 语音转写候选实现

状态：代码候选，尚未完成真实手机、真实 ASR 或企业用户验收。人员同步、SSO、通知及 OA 的验收分别记录，不由本功能的测试结果替代。

## 交付行为

手机钉钉的报障表单可以录制一句话，停止后返回可编辑文字，再整理为草稿。录音、转写和草稿均不能直接建单或执行审批、授权、运维命令。员工必须核对服务、字段、影响范围和紧急程度，明确提交后才能创建工单。PC、非钉钉客户端、非安全上下文、麦克风不可用及服务失败时保留文字路径。

草稿匹配读取当前用户可见且可用的已发布服务目录，依据服务名称、描述中的英文业务名和表单选项生成候选，不固定 ERP/WMS 等系统或工单代码。后台新增服务或字段选项后即可参与匹配；并列、不明确、未发布、无权查看或审批未就绪的服务不会自动选中。字段仅从目录中的唯一匹配选项提取，仍需人工补充影响、紧急程度和其他必填项。此实现为可解释的本地目录规则，尚未接入大模型语义理解。

原有接口为 `GET /api/v1/voice/config`、`POST /api/v1/voice/transcribe`、`POST /api/v1/voice/interpret`，与既有前端兼容。转写输入严格为 `{audio,mimeType,consent:true,contentClass:"GENERAL"}`；audio 为标准 Base64，不接受文件地址、媒体下载链接或客户端选择上游。只有本人有效会话及写操作 CSRF 校验通过后才处理，沿用每人每分钟 10 次入口限制，单 API 进程最多同时处理 2 个转写。

## 条件启用

全部条件同时满足才开放，缺少任何配置自动保持关闭：

| 配置 | 要求 |
| --- | --- |
| `ENABLE_VOICE_ASR` | 精确为 `true` |
| `VOICE_ASR_DATA_BOUNDARY` | 精确为 `internal-approved` |
| `VOICE_ASR_APPROVAL_REF` | 已完成内部音频处理批准的记录编号 |
| `VOICE_ASR_ENDPOINT` | 经企业核实的内网 HTTPS 服务，路径以 `/audio/transcriptions` 结尾，不含 URL 凭据、查询参数或片段 |
| `VOICE_ASR_MODEL` | 该服务实际部署且支持中文的模型标识 |
| `VOICE_ASR_TOKEN` | 私有服务器配置中的服务令牌，不提交仓库 |

配置开关不是批准证明，运维须先核实服务部署位置、网络出口、音频处理和日志保留策略。不可将公共外部服务标记为内部服务。TLS 验证保持开启；内部 CA 通过部署环境的证书信任配置解决。手机麦克风需要可信 HTTPS 入口，当前 LAN HTTP 测试入口只能验收文字路径。

内部转写服务须接受 multipart POST：`file` 为 16 kHz、单声道 PCM WAV，`model` 为配置值，`language=zh`，`response_format=json`，令牌放在 Authorization Bearer 头；成功响应为 JSON `{text:string}`。这是本项目的适配契约，必须对实际模型服务进行兼容性验证；不假定任意本地模型或 sub2api 自动具有 ASR 能力。

## 音频处理与失败行为

- 原始音频上限 2 MB。支持 WebM、Ogg、MP4、WAV；客户端优先选择其实际支持的前三种格式。
- 后端核验声明、Base64 和容器特征，使用 FFmpeg 固定格式输入及只允许 pipe 的协议白名单进行真实解码。解码超时 5 秒，单声道 16 kHz PCM 实际样本上限为 30 秒，不信任客户端时长。前端 29.5 秒自动停止，避免编码尾部导致越界。
- 解码通过标准输入/输出完成，不创建临时录音文件。规范化后的 WAV 发送至固定配置服务，拒绝重定向，30 秒超时，不自动重试。供方响应上限 16 KB，文字上限 4,000 字符。
- 转写文字经过既有敏感内容策略后才返回。安全事件、凭据等被拒绝时，仅记录安全错误码和入口，不记录原文。返回前再次核验当前身份，人员在转写期间停用不能继续接收结果。
- 上传内容、解码结果和完整转写不写入应用日志或数据库；用户确认整理后沿用短期语音草稿规则。应用内不持久化不等于上游不保留，必须另外核查 ASR、反向代理、APM、主机转储及日志配置。
- 取消录音、取消等待麦克风授权、关闭表单或离开页面都会停止捕获。取消的录音不发往转写接口；转写失败保留已输入文字。已发出的请求被取消时，上游可能已收到音频，不能宣称撤回或删除上游副本。

## 验证与剩余门槛

自动化包括配置门槛、音频校验、固定供方契约、异常响应、安全错误、敏感转写拒绝、实际 FFmpeg 多格式解码、过长录音拒绝，以及手机/桌面布局、取消和失败回退。浏览器使用明确的模拟麦克风及转写响应，不能证明真实钉钉或真实模型可用。

音频集成测试同时核对 WAV 头、实际样本数、非静音及已知 440 Hz 信号。碎片 MP4 的 AAC 编码具有帧延迟及尾部填充，1 秒样本按最多两个 1024 样本帧核对；该容差仅用于测试夹具，不放宽生产解码的 30 秒实际样本限制。WAV 和 MP4 各自验证 31 秒录音被拒绝，解码前后检查无录音文件落盘。

现场仍须完成：内部音频处理批准、内网 ASR 和 TLS 配置、可信移动端入口、实际 iOS/Android 钉钉录音、中文及业务名识别、拒绝授权和网络失败、敏感样本拒绝、人员停用、日志检查，最后验证确认前无工单且确认后仅创建一张工单。按照蓝图 A13-A16 和试点员工反馈验收。
