## 统计范围和口径

- 按当前支持组、工单创建日期和 INC/REQ 类型筛选，默认 INC；上海时区，开始与结束日期最多相隔 30 天，完整组范围最多 5000 单，超限要求缩小日期范围。
- 个人维度以 `tickets.assignee_id` 为准，表示查询快照时的实际负责人，不代表创建时、整个日期区间或全过程负责人。
- 尚无实际负责人进入“尚未接单”。候选派单不算接单；交接待确认仍归原实际负责人，接收后才转移。交付任务执行人也不自动算作工单实际负责人。
- 责任分布始终统计本组所选日期与类型的全部工单；总指标和明细再按所选个人筛选。个人下拉项仅来自该范围的实际负责人，不枚举其他组人员或候选人。
- 未结束排除 CLOSED/CANCELLED/REJECTED，包含待确认。另列待接收、等待用户、等待外部、待确认和整单曾超时；不是全历史待办库存，只统计所选创建日期范围。
- 首响、解决/交付、重开、满意度和未批准 SLA 日历规则沿用原整单指标。交接不重置承诺，整单曾超时不能直接归因为当前个人失误或绩效结论。
- 员工姓名及启停状态来自当前人员档案。停用人员仍可作为历史工单的当前负责人显示，并明确标记；不冒充历史姓名快照或恢复账号权限。

## API 契约

`GET /api/v1/reports/summary`

| 参数 | 规则 |
| --- | --- |
| groupId | 必填，只允许本人当前有效成员关系内的支持组 |
| from / to | 必填，YYYY-MM-DD，使用工单创建时间归入上海日期 |
| serviceType | INC 或 REQ；省略为 INC |
| ownerScope | ALL、UNASSIGNED 或 PERSON；省略为 ALL |
| employeeId | 仅 PERSON 必填，非空字符串，最多 200 字符；ALL/UNASSIGNED 不允许携带 |

重复的 ownerScope/employeeId 参数、未知模式及矛盾组合返回 400 `INVALID_REPORT_OWNER_FILTER`。未授权支持组返回 404；身份过滤不扩大组权限，未知或范围外身份返回空明细及零指标，不查询或返回范围外身份资料。

保留旧响应字段，增加：

- `ownerAttribution: CURRENT_ASSIGNEE`：当前实际负责人归属。
- `ownerFilter`：实际应用的模式及员工 ID。
- `asOf`：同一数据库事务的查询时刻。
- `responsibility`：完整授权组范围的当前责任分布，每项包含 employeeId、当前姓名、账号启停状态和指标。
- `items` 中的实际负责人、待接收人及 OFFER/HANDOVER 标识；不返回申请正文、内部备注、OA 绑定或身份密钥。
- `metrics` 中的未结束、待接收、等待用户、等待外部、待确认数量。

在 REPEATABLE READ、READ ONLY 事务中重查有效人员及组成员资格，工单、人员和 SLA 使用一致快照。筛选值使用参数化查询或已授权结果的内存过滤，不拼接 SQL。成员关系在请求前撤销即拒绝；请求过程中权限变化遵循该事务快照，不声称跨事务的即时撤销保证。

## 页面行为

支持“全部负责人”“尚未接单”和具体处理人；停用人员带标记。支持组、类型或日期变化时清除旧结果及个人选项，个人变化时只清除结果，避免将上一次查询误读为新筛选结果。重新查询前保留可选的人员，便于连续对比。

表格区分当前实际责任与候选待接收，展示当前责任分布与明细；宽表在手机内横向滚动，不允许撑宽页面。姓名为当前档案名称，整单 SLA 与历史绩效的区别在报表中明确展示。
