# 一期一句话受理：结构化智能体

## 状态与范围

本文件描述候选实现，须以实际提交的 CI、真实内部模型联调和手机验收分别证明。它与录音及 ASR 是独立适配：文字输入和转写结果调用同一解释接口，不把 sub2api 当作语音识别服务。

服务端先验证本人会话、内容声明与普通内容策略，再取得本人当前可见且可用的已发布服务目录。内部模型仅抽取目录项、简短标题、表单字段和置信度；返回后再次验证本人身份与当前目录，再保存本人草稿。员工可编辑，必须补齐影响范围、紧急程度等信息并明确提交，才会进入现有工单、分派及审批流程。

模型不能执行工具、选择负责人、调整权限、批准申请、发送消息或创建工单。模型输入、输出及服务目录说明均按不可信内容处理。模型建议不构成业务事实证明。

## 部署配置

所有值均由服务器私有环境文件管理，不提交 Git，不通过聊天提供令牌。

| 配置 | 条件 |
| --- | --- |
| `ENABLE_INTAKE_AI` | 精确为 `true` 才尝试调用 |
| `INTAKE_AI_DATA_BOUNDARY` | 精确为 `internal-approved` |
| `INTAKE_AI_APPROVAL_REF` | 实际内部文字处理批准记录编号 |
| `INTAKE_AI_ENDPOINT` | 已核实的内部 HTTPS 接口，路径以 `/chat/completions` 结束；禁止 URL 凭据、查询参数及片段 |
| `INTAKE_AI_MODEL` | 实际部署的模型标识，支持下面的 JSON 返回契约 |
| `INTAKE_AI_TOKEN` | 此内部服务的访问令牌 |

实际服务必须支持非流式聊天补全、`response_format: {type: json_object}`、`max_tokens` 和单条 assistant 内容返回。请求 12 秒超时、不自动重试、不跟随重定向、响应上限 16 KB，每个 API 进程最多两个并发。多个实例的企业配额仍须在内部网关配置。内部证书通过信任链配置，不关闭 TLS 校验。

可使用公司内部模型服务，或经核实仍留在内部处理边界的 sub2api 路由。配置标志本身不证明数据实际留在内部；管理员须核实路由、上游部署、日志保留及出口。当前适配不授权将完整文字转发到外部公共模型。未来外部脱敏路径需单独实现并验收。

## 候选校验与降级

模型 JSON 仅允许 `serviceCode`、`subject`、`fields`、`confidence` 四个属性。服务必须属于本人当前可用目录；字段必须属于对应表单，长度受限，枚举值须完全匹配，字段值须能在原文中找到。标题不超过 80 个字符且无控制字符。未知字段、负责人、审批指令、工具调用、非 JSON 或截断输出均不采用。

置信度低于 0.75 或模型未选服务时，保留原文、清空服务和字段，提示本人选择服务。这个阈值是试点初值，须以脱敏真实样本校准，不能把模型自报置信度当作准确率。模型不可用或配置不完整时，保留目录规则建议和原文，提示核对；未开启模型时继续原有目录规则。输入、生成结果和最终工单均由普通内容策略复查。

地点等自由字段只在当前目录确实配置该字段时抽取。不从模型中采用影响人数、紧急程度、时间推测、负责人或权限决定；这些留给员工确认和既有服务端业务规则。真实相对时间解析尚未纳入本切片。

## 验证与现场验收

- 单元与控制器用例：内部路由完整性、可见目录边界、无工具、未知服务/字段、虚构地点、枚举不符、低置信度、超限响应、失败降级、并发恢复，以及调用期间身份撤销/目录下线。
- 浏览器用例：模型建议可编辑；不预填影响范围与紧急程度；低置信度需手动选择服务；整理草稿不创建工单。浏览器替身只能验证 UI 契约。
- 真实联调：使用批准的模型路由，以已脱敏的 WMS、ERP、网络及权限申请样本核对分类和字段，分别记录模型不可用、低置信度及指令注入结果；不得把 mock 或 CI 记录当作真实调用成功。
- 一期验收仍须在手机钉钉完成免登、录音/转写、编辑、确认创建唯一工单、定向通知、工程师处理及申请审批。需要企业接入配置、实际模型接口和试点用户；本文件不表示这些条件已具备。
